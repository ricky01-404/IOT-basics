IoT Basics Bootcamp

A collection of beginner-friendly IoT projects built during my IoT Basics Bootcamp using Arduino and ESP32 boards. This repository includes basic hardware experiments, sensor integrations, LED control projects, and hands-on learning with embedded systems.

Technologies Used

• Arduino
• ESP32
• C/C++ (Arduino IDE)
• Sensors & Modules
• Basic Electronics

What I Learned

• Basics of IoT and embedded systems
• Working with Arduino and ESP32 boards
• Sensor interfacing and data reading
• LED and buzzer control
• Serial communication
• Basic circuit building and troubleshooting

Projects Included

• LED Blinking
• Push Button Control
• Buzzer Projects
• Temperature/Humidity Sensor
• Distance Sensor
• Basic Automation Projects

Run the Projects
Install Arduino IDE
Connect Arduino/ESP32 board
Upload the .ino file to the board
Open Serial Monitor (if needed)
